Two-tier navbar proto

Click on the top-bar entries above to see how the sub-bar updates contextually. The pattern keeps the top bar minimal (6 entries + flags) while showing all section-relative options on the sub-bar — like Stripe Docs, Vercel, Linear.

HOW IT WORKS The top bar shows 6 main sections. When you're on a page that has siblings (Landscape, Tools, Analysis), the sub-bar below shows them. When the section has no siblings (Anatomy alone, Atlas alone, Buildathon alone), the sub-bar collapses or shows just a context line.

COLOR LOGIC The active section's color (paysage / outil / analyse / etc.) bleeds into the bottom border of the top-bar entry AND the top border of the sub-bar — visual continuity, no need to re-state colors per link.

MOBILE Both tiers wrap with flex-wrap, the sub-bar can collapse into a horizontal scroll if too long.
