Calculation assumptions · sources

XRPL: dynamic base fee ~10 drops = ~$0.000004 + average AMM spread ~$0.001 for swap → rounded to $0.001/tx. Stellar: 0.00001 XLM + dynamic amplification → $0.002/tx. Solana: 5000 lamports base + average priority fee $0.003 → $0.005/tx. Ethereum: average gas 21k @ 20 gwei + ETH ~$3500 → ~$2.50/tx (±50% variability based on congestion).

The simulator excludes: dev infrastructure costs (RPC nodes, indexers, monitoring), compliance/KYC costs, marketing costs. See Business Case Builder for those components.
