09 · AI × Payments · agentic

2 entries · emerging category
Structurally new category that emerged with AI agents (OpenAI Operator, Claude Computer Use, Vercel AI agents). The x402 (HTTP 402 "Payment Required") standard revived by Coinbase lets agents pay for APIs in crypto without login. Implemented on Base/USDC. XRPL is technically ideal for this use case (~0.00001 XRP/tx, 3–5s finality, native payments) but no facilitator exists yet — explicit gap.

x402 standard (Coinbase)

External
HTTP 402 · Open standard

Open spec (Coinbase, 2024) that reuses the HTTP 402 Payment Required code to let a client (often an AI agent) pay an API request in crypto. Live on Base with USDC. Spec is chain-agnostic by design — natively adoptable on XRPL.

Coinbase specgithub.com/coinbase/x402

Facilitator XRPL

Vacant
Opportunity gap · à builder

No one has yet implemented an x402 facilitator on XRPL. Minimal stack: HTTP middleware + on-chain Payment verify via xrpl.js + memo nonce. For multi-step / quotas: SetRegularKey + conditional escrow. See the r-x402-agent path in the decision-tree and the dedicated gap in the global gaps view.

Opportunity Gaps · preview

→ See the global view (12 gaps)

Gap 01 · Wallets

B2B treasury wallet · XRPL-native

No Coinshift- or Utopia Labs-style enterprise wallet dedicated to XRPL. Multisig + approval workflows + compliance audit trail + accounting integration. Market: DAOs and crypto companies paying contributors or buying in stablecoin.

Gap 02 · Infra

B2B monitoring & alerting

No Tenderly or Forta equivalent for XRPL. Transaction monitoring, anomaly alerts, pre-execution simulation, business dashboards. Market: every startup in production that needs visibility without building its own stack.

Gap 03 · DeFi

Native yield aggregator

Sologenic and XPMarket don't cover cross-protocol yield aggregation (AMM LP + lending + sidechain staking). Yearn-XRPL doesn't exist. Market: retail crypto users wanting to max yield without manual management.

Gap 04 · Identity

Reusable cross-app KYC

XLS-70 DID + Credentials are available, but no "KYC-as-a-Service" capitalizes on them to offer reusable KYC across apps. Market: huge, cross-cutting all RWA and compliance apps.

Gap 05 · Payments

Regional POS / merchant tooling

M-Pesa challenger in Africa (cf. MerchantPay blueprint), LATAM POS, MiCA-compliant European terminal... No regional player dedicated to merchants. Market: huge, with local entry barriers (boots-on-the-ground).

Gap 06 · RWA

Mid-market corporate bonds

Spiko targets MMFs, OpenEden T-bills. No one covers the €5–50M mid-market corporate bond underserved by banks. This is exactly the BondBloc pitch from the Builder Atlas. EU market: €80B potential stock.
