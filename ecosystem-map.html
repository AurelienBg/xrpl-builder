01 · DeFi & DEX

7 projets · catégorie active
L'AMM XLS-30 est natif depuis mars 2024. L'écosystème DEX est mature mais reste dominé par 2-3 acteurs principaux. Liquidité concentrée sur paires XRP/RLUSD et XRP/USDC. La sidechain EVM ouvre des opportunités côté DeFi avancée (perps, lending) qui restent largement inoccupées sur le L1.

09 · AI × Payments · agentic

2 entrées · catégorie émergente
Catégorie structurellement nouvelle apparue avec les agents IA (OpenAI Operator, Claude Computer Use, Vercel AI agents). Le standard x402 (HTTP 402 "Payment Required") relancé par Coinbase permet aux agents de payer des APIs en crypto sans login. Implémenté sur Base/USDC. XRPL est techniquement idéal pour ce use case (~0.00001 XRP/tx, finalité 3–5s, native payments) mais aucun facilitator n'existe encore — gap explicite.

x402 standard (Coinbase)

External
HTTP 402 · Open standard

Spec ouverte (Coinbase, 2024) qui réutilise le code HTTP 402 Payment Required pour permettre à un client (souvent agent IA) de payer une requête API en crypto. Implé live sur Base avec USDC. Spec chain-agnostic dans le design — adoptable sur XRPL nativement.

Spec Coinbasegithub.com/coinbase/x402

Facilitator XRPL

Vacant
Opportunity gap · à builder

Aucun acteur n'a encore implémenté un facilitator x402 sur XRPL. Stack minimale : middleware HTTP + verify Payment on-chain via xrpl.js + memo nonce. Pour multi-step / quotas : SetRegularKey + escrow conditionnel. Voir le path r-x402-agent dans le decision-tree et le gap dédié dans la vue globale gaps.

Opportunity Gaps · aperçu

→ Voir la vue globale (12 gaps)

Gap 01 · Wallets

Treasury wallet B2B XRPL-native

Aucun wallet d'entreprise type Coinshift ou Utopia Labs dédié XRPL. Multisig + approvals workflows + audit trail compliance + intégration accounting. Marché : DAOs et entreprises crypto qui paient des contributeurs ou achètent en stablecoin.

Gap 02 · Infra

Monitoring & alerting B2B

Pas d'équivalent Tenderly ou Forta pour XRPL. Monitoring transactions, alertes anomalies, simulation pre-execution, dashboards business. Marché : toutes les startups en production qui ont besoin de visibilité sans builder leur stack.

Gap 03 · DeFi

Yield aggregator natif

Sologenic et XPMarket ne couvrent pas l'agrégation cross-protocole de yield (AMM LP + lending + staking sidechain). Yearn-XRPL n'existe pas. Marché : detail crypto qui veut maximiser le yield sans gérer manuellement.

Gap 04 · Identity

KYC reusable cross-app

XLS-70 DID + Credentials sont disponibles, mais aucun service "KYC-as-a-Service" ne capitalise dessus pour offrir un KYC réutilisable d'une app à l'autre. Marché : énorme, transverse à toutes les apps RWA et compliance.

Gap 05 · Payments

POS / Merchant tooling régional

M-Pesa challenger en Afrique (cf. blueprint MerchantPay), POS LATAM, terminal européen MiCA-compliant... Aucun acteur régional dédié aux merchants. Marché : énorme, avec barrière d'entrée locale (terrain).

Gap 06 · RWA

Mid-market corporate bonds

Spiko vise les MMF, OpenEden les T-bills. Personne ne couvre le mid-market corporate bond 5-50M€ qui est mal servi par les banques. C'est exactement le pitch BondBloc du Builder Atlas. Marché EU : 80 G€ de stock potentiel.
